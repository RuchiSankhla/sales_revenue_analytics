#### **Sales Revenue Analytics using SQL**

#### **Project Overview**



This project focuses on analyzing sales revenue data using SQL to derive meaningful business insights.

The dataset used is the Superstore Sales dataset, and the analysis covers sales performance, customer behavior, product trends, and regional insights.



The goal of this project is to demonstrate strong SQL skills including data exploration, aggregation, time-based analysis, window functions, and data validation.



###### **-- Dataset Description**

* Dataset Name: Superstore Sales
* Data Source: Public retail sales dataset
* Database: MySQL
* Table Name: train



###### **-- Key Columns**



* Order ID
* Order Date
* Customer ID
* Customer Name
* Segment
* Category
* Sub-Category
* Product Name
* Region
* State
* City
* Sales



###### **-- Tools \& Technologies**



* MySQL
* MySQL Workbench
* Microsoft Excel (for cross-validation)
* GitHub

###### **-- Analysis Performed**



**-- Phase 1: Data Exploration**



* Sample data inspection
* Basic table structure check
* Descriptive statistics (total, average, min, max sales)



**-- Phase 2: Data Quality Checks**



* NULL value analysis
* Column data validation



**-- Phase 3: Product \& Sales Analysis**



* Total sales calculation
* Top 10 products by sales
* Category-wise and sub-category-wise sales analysis



**-- Phase 4: Time-Based Analysis**



* Year-wise sales trend
* Month-wise sales trend
* Date cleaning and conversion



**-- Phase 5: Customer Analysis**



* Top 10 customers by sales
* Customer distribution by segment



**-- Phase 6: Region \& Location Analysis**



* Region-wise sales
* State-wise sales
* City-wise sales



**-- Phase 7: Advanced SQL**



* Window function to rank products by sales
* CASE statement for sales classification



**-- Phase 8: Validation**



* Cross-checking total sales between SQL and Excel



###### **-- Key SQL Concepts Used**



* Aggregate functions (SUM, AVG, MIN, MAX)
* GROUP BY and ORDER BY
* Date functions (YEAR, MONTH, STR\_TO\_DATE)
* Window functions (RANK)
* CASE statements
* Data validation techniques



###### **-- Results \& Insights**



* Identified top-performing products and customers
* Analyzed sales trends across years and months
* Observed regional and category-based performance differences
* Ensured accuracy through Excel and SQL cross-validation



###### **-- Conclusion**



This project demonstrates practical SQL skills applied to a real-world sales dataset.

It reflects an end-to-end data analysis workflow including data preparation, analysis, validation, and reporting.
